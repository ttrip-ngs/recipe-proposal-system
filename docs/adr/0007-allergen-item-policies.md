# ADR 0007: 通常は除去不要な食品の可/不可をメンバーごとに選ばせる (未選択は除去)

- Status: Accepted
- Date: 2026-09-27

## Context

アレルゲン辞書は「表記 -> canonical -> アレルゲングループ」の 1 表記 1 canonical 構造で、
加工品・調味料の扱いが食品ごとにばらばらだった。

- 醤油は `大豆` の別表記: 大豆アレルギーでは常に除去、小麦アレルギーでは一切除去しない
- 味噌は 2026-09 の修正 (memo/history/028) で大豆グループに入り、大豆アレルギーで常に除去
- ごま油は `ごま` の別表記: ごまアレルギーで常に除去
- 卵殻カルシウム・乳糖などは辞書に無い

公的なガイドラインは、これらを「多くの患者が摂取できる食品」として扱い、除去は医師の指示で
個別に決めるとしている。

- 食物アレルギーの診療の手引き2023 (厚生労働科学研究班) 表16「原則として除去不要の食品」:
  鶏卵 = 卵殻カルシウム、牛乳 = 乳糖・牛肉、小麦 = 醤油・酢・麦茶、大豆 = 大豆油・醤油・味噌、
  ゴマ = ゴマ油、魚 = かつおだし・いりこだし、肉類 = エキス。「除去指示する場合は慎重に行なう」
  https://www.foodallergy.jp/wp-content/uploads/2026/04/FAmanual2023_260410.pdf (p.25)
- 食物アレルギーの栄養食事指導の手引き2022: 完全除去でも調味料 (醤油・味噌・油・ダシ) が
  摂取可能か医師に確認する。ピーナッツはピーナッツオイルも除去、甲殻類のエキスは個人差あり
  https://www.foodallergy.jp/wp-content/uploads/2026/04/nutritionalmanual2022-20260406.pdf
- 保育所・学校の生活管理指導表「より厳しい除去が必要なもの」欄: 上記の食品に医師が○を付けた
  ものだけ除去する (学校版は小麦に味噌、乳に乳清焼成カルシウム、魚に魚醤を追加)
  https://www.gakkohoken.jp/book/ebook/ebook_R010100/R010100.pdf
- 消費者庁のアレルゲン表示は「含むか」で決まり、醤油には必ず小麦・大豆が表示される。
  表示を機械的に照合すると除去しすぎになる (消費者庁自身も言及)

現状は大豆アレルギーで除去しすぎ (醤油が使えない和食はかなり限られる)、小麦アレルギーで
厳しい除去が必要な人を守れていない、の両方の問題がある。

## Decision

- `allergens.yaml` の各グループに `usually_tolerated` (members の部分集合) を持たせる。
  収録: 卵 = 卵殻カルシウム、乳 = 乳糖・乳清焼成カルシウム、小麦 = 醤油・酢・麦茶・味噌、
  大豆 = 醤油・味噌・大豆油、ごま = ごま油 (診療の手引き表16 と学校版の和集合)
- 醤油・ごま油などは独立 canonical にする。醤油は 大豆 と 小麦 の両グループに属する
- メンバーに `item_policies` (アレルゲン -> {食品 -> allow / block}) を持たせる。家族設定画面で
  アレルゲンを選ぶと、その食品の可/不可を **選択必須** (初期選択なし) で聞く。サーバ側で
  未選択なら保存しない
- **未選択の食品は除去 (block) 扱いにする**。ガイドライン・生活管理指導表の初期値は「可」だが、
  このシステムの誤りは健康被害に直結し、既存メンバー (本機能の導入前に登録) は選択していない。
  安全側の既定にし、画面で「未設定 (除去扱い)」を表示して選択を促す
- 判定は `validators.blocked_allergens` に一本化し、事前フィルタと事後検証の両方が使う。
  複数グループに属する食品 (醤油) は、該当する全アレルゲンで allow のときだけ摂取可
- 摂取可の食品名はアレルゲンの語を含む (ごま油 -> ごま) ため、手順などの部分一致検査では
  許可された食品の表記を伏せてから照合する
- LLM には「大豆 (醤油・大豆油は使用可、味噌も除去)」の形で伝える (プロンプト YAML は変えない)
- 判定は決定論的コードのまま (CLAUDE.md 6.1)。LLM・外部モデルは関与しない

## Consequences

### 正の影響

- 医師の生活管理指導表をそのまま書き写せる。大豆アレルギーでも醤油・味噌を使った献立が出せる
- 小麦アレルギーで醤油の厳しい除去が必要な人を守れる
- 事前フィルタと事後検証の判定が一致する

### 負の影響

- **デプロイ直後の挙動変化**: 既存の 小麦・卵・乳・ごま アレルギーのメンバーは可/不可が未選択の
  ため、醤油・味噌・酢・ごま油などを使う料理が提案されなくなる。migration の dry-run で
  未選択の一覧を出し、デプロイ後すぐに家族設定で選ぶ (scripts/migrate_add_item_policies.py)
- 醤油の canonical が `大豆` から `醤油` に変わるため、`dislikes: [大豆]` は醤油を捕まえなくなる
  (苦手食材としては正しい挙動)
- LLM への入力文字列が変わる。Fake のゴールデン評価は合格。実 LLM (--live) 評価は API
  クレジット補充後に実施する

### 将来の検討

- 魚のだし (かつお・いりこ)・魚醤、肉のエキスは、辞書が対象 (かつお・いりこ等、エキスの表記) を
  持たないため未収録。魚類グループの拡張と合わせて検討する
- カニカマ・ソーセージ類など「製品によって含むことがある」加工品は別の問題 (含有の不確実性) で、
  本 ADR の対象外 (memo/history/028 残課題)
