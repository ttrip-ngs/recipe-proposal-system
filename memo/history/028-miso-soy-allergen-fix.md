# 028 味噌に大豆のアレルゲンタグが付かない不具合の修正

2026-09-27

## 背景

食材判定に TypeSafe Jev を使えるか検討する中で `aliases.yaml` を洗い出したところ、
「味噌」「みそ」が `大豆` の別表記と canonical `味噌` (苦手食材指定用, household-custom)
の両方に登録されていた。ローダーは後勝ちで上書きするため、実際には

```
normalize("味噌") -> ('味噌', {'味噌'})   # 大豆が付かない
```

となり、大豆アレルギーの家族がいても食材リストの味噌では block されなかった。
手順の文章検査でも、大豆の検査語に味噌の別表記 (白味噌など) が含まれていなかった。
辞書内の重複はこの 1 件のみ。

## 対応

- `aliases.yaml` (version 4): `大豆` の別表記から 味噌 / みそ を削除
- `allergens.yaml` (version 3): `大豆` グループの members に `味噌` を追加。
  canonical `味噌` は苦手食材の指定に使えるまま、アレルゲン判定では大豆として扱われる
- `dictionary_loader.load_dictionary`: 1 つの表記が複数の canonical に登録されていたら
  `ValueError` で起動を止める (大文字小文字は区別しない)。同種の後勝ち上書きの再発防止
- `docs/guardrails.md` §2.2 に重複禁止のルールと、加工品を独立 canonical にする場合の書き方を追記

## テスト

`tests/guardrails/` に追加:

- 味噌の表記 6 種がすべて canonical `味噌` + 大豆タグになる
- 手順検査の大豆の語に 味噌 / 白味噌 が含まれる
- 重複登録 (大文字小文字違いを含む) でロードが失敗する
- 大豆アレルギーの家族に味噌を使う料理が block される (正規化から検証まで通し)

修正前に 5 件が失敗することを確認してから修正した。

## 残課題

- 醤油は `大豆` の別表記のみで、小麦タグが付かない。一般的な濃口醤油は小麦を原料に含む。
  小麦アレルギーでも醤油は摂取可とされることが多く (醸造で小麦たんぱくが分解される)、
  家庭ごとに扱いが分かれるため、この修正では変更していない。判断が必要
- 本番 Firestore に保存済みの献立は再検証していない。味噌を含む過去の献立が大豆アレルギーの
  家族向けに通っていた可能性がある
